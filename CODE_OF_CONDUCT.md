# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: we are committed to a welcoming, harassment-free environment for everyone, regardless of
background, career stage, institution or country. Be respectful, give constructive feedback, credit others' work.

Concerns can be reported confidentially to the maintainers at: **opengeomaticseducation@gmail.com** *(replace with the group address)*.
Reports will be reviewed promptly and handled with discretion.

> Tip: to include the full text, open `Add file → Create new file`, name it `CODE_OF_CONDUCT.md`, and
> GitHub will offer the Contributor Covenant template automatically.
